# Capabilities, Limits, and Module Controls

ExactSurface is **100% free and open for self-hosted instances**. Once delivered/built, there are no domain restrictions, user caps, feature paywalls, or read-only subscription enforcement.

---

## 1. Capabilities & Limits Overview

| Feature / Metric | Self-Hosted Status |
|---|---|
| **Domains** | Unlimited |
| **Users / Members** | Unlimited |
| **API keys** | Unlimited |
| **Re-scan cadence** | Unlimited (customizable schedules, no floor) |
| **History retention** | Full history retained |
| **403 Bypass & Reports** | Included |
| **All Modules** | All 28+ modules enabled and togglable |

Every self-hosted instance runs with full capability right out of the box with zero license keys or recurring billing restrictions.

---

## 2. Module Controls

All 28+ detection modules are fully unlocked for all users. Individual modules can be toggled **ON** or **OFF** on the **Scan modules** card on each program:

* **Subdomain Discovery** (`ingest`) — Essential spine
* **Live-Host Probing** (`probe`) — Essential spine
* **Crawling & Archives** (`crawl`)
* **Content Discovery** (`content_discovery`)
* **Vulnerability Scanning** (`scan` / Nuclei)
* **Exposed Secrets** (`secrets`)
* **CVE Watch** (`cve_watch`)
* **TLS Inspection** (`tls`)
* **Service Fingerprinting** (`service_scan`)
* **Hidden Parameters** (`param_discovery`)
* **Lookalike Domains** (`typosquat`)
* **Cloud Storage Exposure** (`cloud_buckets`)
* **Cloud Asset Inventory** (`cloud_assets`)
* **Internet-Index Search** (`uncover` — Shodan/Censys)
* **New-Template Watch** (`nuclei_watch`)
* **Search-Engine Exposure** (`dork`)
* **Dependency Confusion** (`supply_chain`)
* **Subdomain Takeover** (`takeover`)
* **JavaScript Mining** (`js_mine`)
* **API & Path Disclosure** (`api_surface`)
* **CORS, Redirects & WAF** (`http_misconfig`)
* **Port Scanning** (`port_scan`)
* **Broken-Link Hijacking** (`broken_links`)
* **Public Code Leaks** (`github_osint`)
* **Reverse-DNS Sweep** (`reverse_dns`)
* **Domain Intelligence** (`domain_intel`)
* **Risk Correlation** (`correlate`)
* **Alerting & Notifications** (`notify`)
